Form Builder

Build a scouting form by creating sections and appending questions.

Append-only form: Once the sections are created, their titles and existing questions cannot be changed or removed here. You can continue adding questions to any section.

1. Form setup

3
Choose 1–9 sections. The default is 3.

2. Add questions

Select a section, configure a question, and append it. Existing elements are displayed as read-only previews.

Used for short-answer and paragraph questions. Questions are optional.

3. Save form

Save to Token sends the form dictionary as JSON to /Builder_Form_reponse. Token creation and storage are handled by your backend. 

Create your sections to begin.
